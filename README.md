# CMS-CCM-Application (Career Counseling Management Application)

## 📌 Project Overview
This project is a career counseling management application designed to support counselors in recording, tracking, and analyzing counseling sessions in a structured and efficient way.

The system was developed as an internal tool for an organization in the education sector. Due to confidentiality and data privacy policies, no real data, organization names, or internal assets are shared in this repository.

This repository serves as a **documentation and portfolio showcase** of the system design, workflow, and reporting logic.

---

## 🎯 Problem Statement
Before this application, counselors documented counseling sessions using Microsoft Forms. Session data was later exported to Excel, where monthly reports were prepared manually. In addition, feedback requests were sent separately to students after each counseling session.

This process was:
- Time-consuming
- Prone to inconsistencies
- Highly manual
- Limited in reporting and insight generation

---

## 💡 Solution
A centralized low-code application was developed to replace the fragmented workflow. The application automates session data collection, feedback distribution, and reporting within a single integrated system.

---

## 🧩 Key Features
- Centralized Power Apps interface for counseling session data entry
- Automated storage of session data in structured Excel tables
- Automatic feedback email sent to students after each session
- Monthly and real-time reporting via Power BI dashboards
- Data cleaning and transformation pipeline in Power BI (Power Query)
- Reduced manual reporting and administrative workload

---

## 🔄 Process Improvement (Before vs After)

### Before
- Microsoft Forms used for session documentation
- Manual Excel exports and monthly reporting
- Separate feedback email process
- Limited data visibility and delayed insights

### After
- Single Power Apps system for all session records
- Automated data storage and reporting
- Automatic feedback emails sent after each session

## 📊 Reporting & Analytics
The application integrates with Power BI to generate automated dashboards providing insights such as:
- Counseling session volumes
- Meeting type distribution
- Engagement trends over time
- Operational performance indicators

All dashboards are based on internal data and are not publicly shared.
